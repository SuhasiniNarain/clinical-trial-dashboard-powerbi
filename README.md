# clinical-trial-dashboard-powerbi
Interactive Power BI dashboard for clinical trial and patient analytics
Clinical Trial Analytics Dashboard using Power BI
Project Overview

This project focuses on interactive clinical trial analytics using Power BI to analyze patient demographics, treatment groups, laboratory values, and adverse events.

The dashboard was designed to support healthcare and clinical data exploration through dynamic visualizations and filtering.

Key Features
Patient demographic analysis (age, sex, BMI, race)
Treatment arm comparison (ARM A, ARM B, ARM C)
Laboratory value tracking over time
Adverse event monitoring and trend analysis
Interactive filtering using slicers
Custom R-based visualization inside Power BI
